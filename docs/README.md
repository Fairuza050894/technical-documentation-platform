# Documentation Portal

| Field | Value |
|---|---|
| Document ID | TDP-DOC-001 |
| Status | Controlled draft |
| Owner | Technical Documentation |
| Classification | Internal project documentation |
| Review cadence | At each material change or release |
| Source of truth | This repository |

This portal is the canonical entry point for documentation about the Technical Documentation Platform itself. It is separate from customer documents generated by the platform.

## Documentation model

```text
Human-governed documents
├── product intent
├── architecture decisions
├── requirements
├── risk and compliance decisions
└── approval records

Deterministically generated documents
├── repository inventory
├── ADR index
├── requirements index
├── API surface
├── frontend route index
├── test inventory
└── document register
```

Human-governed documents are edited through reviewed commits. Generated documents are produced by `make docs` and verified by `make docs-check`.
